        Como manter atualizado

        Clique em ✏️ Editar dados para ajustar valores, adicionar/remover itens e atualizar a meta. Tudo é salvo automaticamente neste navegador (nada vai para a internet). Use Restaurar para voltar aos números originais.

        Para classificar os investimentos por tipo (Renda Fixa, Ações, COE, FIIs…) e preencher o aporte e a rentabilidade mensal, me envie no chat os extratos de fechamento de cada banco — eu leio, extraio saldo, aportes e rendimentos, classifico ativo por ativo e devolvo os dados prontos para colar aqui.
